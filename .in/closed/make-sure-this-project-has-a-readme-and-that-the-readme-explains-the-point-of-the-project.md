## Questions for a new product manager

1. Should I update the existing `README.md`, or create a new README in a specific folder?
2. Who is the README for: people trying the standalone demonstration, developers installing the browser extension, or both?
3. What should a new reader understand after the first paragraph: what Fitts’ Law means, what this project demonstrates, or how to use it?
4. Should the README include installation and usage instructions as well as the project’s purpose?
